# Pagination QA Briefs

Static MVP for checking pasted pagination HTML, page URL examples, canonical/noindex rows, UX notes, and sitemap representative URLs before ecommerce, publisher, documentation, marketplace, or migration launches.

## Offer

Paste pagination snippets, page URL examples, optional canonical/noindex rows, UX notes, sitemap samples, and site type. Generate a copyable QA brief covering:

- missing `a href` links for next, previous, and page-number controls
- button-only load-more controls
- infinite-scroll risk
- fragment-only page URLs
- missing unique page URL patterns
- page 2+ canonicalized to page 1
- noindex on important paginated URLs
- missing sequential links
- missing sitemap fallback for page 2+ URLs
- generic or empty anchor text

## Conversion Path

Billing is not connected. The MVP uses early-access, demo-request, and purchase-intent capture with a public-safe GitHub issue handoff.
